# A little surprise for Disha ♡

A mobile-friendly romantic website made by Kunal for Disha. Includes her uploaded photos, a featured image, a clickable Polaroid-style gallery, letter, animations, and a Hindi-song search shortcut.

## Preview locally
Open `index.html` in a modern browser. Keep the `photos` folder beside it.

## Publish free with GitHub Pages
1. Create/sign in at https://github.com
2. Create a public repository, e.g. `disha-surprise`.
3. Upload `index.html` AND the entire `photos` folder.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then **Save**.
6. Wait for GitHub to show your public URL, typically `https://YOUR-USERNAME.github.io/disha-surprise/`.
7. Open the link on your phone to test it.

## Add the exact song
The page currently has a shortcut to search for the song because "Alfaaz" could refer to more than one track. If you send the exact YouTube link, the music section can be updated to embed the correct video. Browsers generally block autoplay, so the visitor should press play.

## Privacy
Anyone with the public link can view the photos. Only publish photos you have permission to share, and avoid adding private messages, phone numbers, or addresses.
